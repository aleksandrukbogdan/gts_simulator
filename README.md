# 🛢️ GTS Simulator — Симулятор газотранспортной системы

Интерактивный веб-симулятор газотранспортной сети с AI-ассистентом для анализа аварийных сценариев.

![Интерфейс приложения](https://img.shields.io/badge/React-18.2-blue) ![Vite](https://img.shields.io/badge/Vite-5.0-purple)

---

## 📖 Что это за проект?

**GTS Simulator** — это веб-приложение, которое визуализирует газотранспортную сеть (магистральные газопроводы, компрессорные станции) и позволяет:

- 🗺️ **Просматривать карту сети** — интерактивная схема с узлами (станциями) и трубопроводами
- ⚠️ **Симулировать аварии** — выбрать участок и увидеть последствия аварии (снижение давления, затронутые станции)
- 🤖 **Общаться с AI-ассистентом** — задавать вопросы о системе, получать рекомендации по ликвидации аварий
- 📊 **Видеть параметры** — давление, расход газа, температура на каждом элементе сети

### Для кого это?

Проект создан как демонстрация концепции интеллектуальной системы мониторинга для газотранспортных предприятий.

## 🚀 Как запустить проект?

### Что нужно для запуска

1. **Node.js** — программа для запуска JavaScript на компьютере
   - Скачать тут: https://nodejs.org/
   - Выберите версию "LTS" и установите как обычную программу

### Шаги для запуска

1. **Скачайте проект** (если ещё не скачали)
   - Нажмите зелёную кнопку "Code" на GitHub → "Download ZIP"
   - Распакуйте архив в любую папку

2. **Откройте терминал в папке проекта**
   - Windows: откройте папку в проводнике → в адресной строке напишите `cmd` и нажмите Enter
   - Или: кликните правой кнопкой мыши в папке → "Открыть в терминале"

3. **Установите зависимости** (первый раз)
   ```
   npm install
   ```
   Это скачает все необходимые библиотеки. Подождите пару минут.

4. **Запустите приложение**
   ```
   npm run dev
   ```

5. **Откройте в браузере**
   - После запуска появится ссылка вида `http://localhost:5173`
   - Кликните по ней или скопируйте в браузер

### Как остановить?

В терминале нажмите `Ctrl + C`

## 🎮 Как пользоваться?

### Карта сети

- **Кликните на станцию или трубопровод** — увидите параметры в левой панели
- **Зелёные линии** — трубопроводы, на них указан расход газа
- **Точки на карте** — станции разных типов (компрессорные, газоизмерительные и т.д.)

### AI-ассистент (справа)

Напишите вопрос в чат, например:
- "Что будет при аварии на участке 1?"
- "Покажи статус системы"
- "Какой состав газа?"

Или используйте **быстрые кнопки** для симуляции аварий.

### Симуляция аварий

1. Нажмите кнопку "Simulate: Line 1 Rupture" в чате
2. На карте подсветится аварийный участок (красным/оранжевым)
3. Вверху появится баннер с информацией об аварии
4. Нажмите "✕ Clear" чтобы сбросить симуляцию

## ❓ Частые проблемы

### "npm: command not found"
Node.js не установлен. Скачайте с https://nodejs.org/

### "Port 5173 is in use"
Другое приложение занимает порт. Закройте его или используйте:
```
npm run dev -- --port 3000
```

### Ошибки при установке
Попробуйте удалить папку `node_modules` и файл `package-lock.json`, затем снова `npm install`
